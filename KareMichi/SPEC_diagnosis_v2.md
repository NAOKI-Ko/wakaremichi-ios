# 診断 v2 仕様(未着手・バックログ)

企画側から提示された2つの分析文書をもとにした仕様。**今回のセッションでは
着手しない。** コアの継続率検証が終わってから、着手するかどうか判断する。

小さい部分(14日間の繰り返しパターン、条件付きレア文章3つ、ブランディング方針)
は既に `Diagnosis.swift` / `ResultView.swift` に実装済み。ここに書くのは
それ以外の、規模の大きい未着手部分。

---

## 1. ランダムイベント(最重要・最大の未着手項目)

**核心のアイデア**: 「自分で選んだ答え」と「迷路内で無意識に出た行動」を
比較する。これは通常の心理テストにはできない、このゲーム固有の強み。

### 設計原則(必ず守ること)

- **選択肢に得失をつけない。** 「この選択肢なら宝箱がもらえる」が分かると、
  プレイヤーは自分らしい選択ではなくゲーム的に得な選択をするようになり、
  診断データとしての意味が薄れる。演出の違いはあってもいいが、得失は
  ほぼ同じにする
- **どの選択肢も「悪くない」ように書く。** 「困っている人を助けるか」の
  ような、答えが読めてしまう(助ける=優しい)問いは避ける。3択とも
  それぞれ違う理由で妥当に見えるように書く
- **頻度は1日1〜2回まで。** 迷路が主役なので、イベントは「その日の心を
  映す一点」に留める
- **直近7日で同じテーマを避ける制御が必要**(昨日と似た問いが続かないように)
- **解除条件は表示しない。** 見せると自己反映ではなく実績解除ゲームになる

### テーマ分類(4軸に直接対応させず、テーマで分類する)

未知(近づく/観察する/避ける)、過去(持ち帰る/置いていく/記録する)、
他者(助ける/見守る/距離を取る)、決断(今決める/保留する/別案を探す)、
喪失(探す/受け入れる/形を変えて残す)、目的(最短を選ぶ/寄り道する/
目的自体を変える)。内部では4軸へ変換してよいが、プレイヤーには見せない。

### イベント例(企画側の下書き、そのまま使える)

```
消えかけた手紙
岩の隙間に、半分だけ燃えた手紙が挟まっている。宛名は読めない。
- 残った部分を読む
- 元の場所へ戻す
- 持ち帰る

もう一人の足音
自分のものではない足音が、少し遅れてついてくる。
- 立ち止まって待つ
- 振り返らず進む
- 違う道へ入る

二つの灯り
片方は明るいが、もうすぐ消えそうだ。もう片方は弱いが、長く燃えそうに見える。
- 明るい灯りを選ぶ
- 長く燃える灯りを選ぶ
- 今の灯りを使い続ける

古い地図
壁に貼られた地図は、今の洞窟と形が違う。
- 地図を信じて進む
- 参考にだけする
- 見なかったことにする
```

### 結果への重み付け(企画側の推奨)

迷路行動60% / イベント選択20% / 探索前後の気分10% / 過去平均との差10%。
イベントは結果を決める主役ではなく、行動を解釈する「文脈」として使う。

### 一致/不一致の文章化(核心部分)

イベントで選んだ選択と、実際の行動が一致する場合・しない場合で、
それぞれ別の文章を用意する。例:

```
[一致の例]
音のする方へ進むことを選びました。
迷宮でも、見えていない道へ何度も足を向けています。
今日は、自分でも感じていた好奇心と、歩き方がよく重なっていました。

[不一致の例]
音のする方へ進むことを選びました。
けれど実際の旅では、見知った道を丁寧にたどっています。
興味はありながら、今日は足元を確かめたい気持ちもあったのかもしれません。
```

### 実装方針

LLMでの毎日自由生成ではなく、**人間が書いた部品をルールで組み合わせる**
方式を推奨(企画側の推奨と一致)。各文章に「探索性が高い」「早抜け」
「前日比」のようなタグをつけ、矛盾する部品を同時に選ばないルールを作る。

## 2. レア文章の拡張(30〜50個)

現状3個(`Diagnosis.conditionalRareText`)実装済み。企画側は30〜50個を
推奨。追加候補(企画書からの抜粋):

```
[ワープ後、元の場所を探し直した]
遠くへ運ばれたあとも、あなたは失ったつながりを探しました。
新しい場所へ進むことと、過去を置き去りにすることは違います。
```

判定条件は実装時に、既存のログ(RunLog)で機械的に検出できるものから
優先すること。「気持ちの動き」を伴う条件(喪失感、など)は行動ログだけ
からは判定できないので、無理に作らない。

現状、この階層は部分的にしか実装されていない:

軽い計算(直近3日と直近1日の単純比較)で作れるはず。

## 4. 結果画面の再構成(5枚→意味を持たせた5枚)

企画書は、既存5枚を以下の役割に再構成することを提案している:

1. 今日の軌跡(事実、数字は少なめ)
2. 今日の旅姿(人格化+根拠の数値を小さく併記)
3. 心の分かれ道(自己申告と行動のズレ) ← 現行の「今日のひとこと」に相当
4. 洞窟の返書(上位3特徴から2〜4文を生成、一番エモーショナルな読み物)
5. 明日へ持ち帰る道しるべ(占い的、未来を断言せず小さな行動を提案)

現行の5枚(軌跡/傾向/ひとこと/称号/道しるべ)+鏡(条件付き6枚目)と
役割はかなり近いが、「洞窟の返書」(上位3特徴だけを選んで文章化する)は
今の`comment()`関数がまだやっていない設計。今は「一番高い軸1つ」しか
見ていないので、**上位3つの特徴を選んでから文章を組み立てる**方式への
書き換えが必要(こじつけを避けるため、全データを見せるのではなく
特徴的な3つだけに絞る、という企画書の指摘は重要)。

## ブランディング方針(実装ではなく方針、既にREADMEに反映済み)

「性格を正確に測定する」とは名乗らない。ストアでは「心理テスト」より
「歩き方から、今日の自分を映す探索ゲーム」。ゲーム内では「診断結果」
ではなく「洞窟の返書」「今日の道読み」のような言葉を使う。医療的・
科学的な性格測定を名乗ると、方法や正確性の根拠を求められるリスクがある。
